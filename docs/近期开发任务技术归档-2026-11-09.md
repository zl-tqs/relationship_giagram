## 3. 最新任务详情

### 3.1 关系连线显示重构（未提交，代码）

**背景与问题**

- `RelationData` 同时存在 `type`（关系类型）与 `label`（标注文字）两个语义重叠字段，属性面板提供两个输入框，数据含义不清。
- 旧实现把 `type`、`color`、`width`、`arrow` 写入 `edge.data` 后，直接将 `edges` 传给 React Flow，没有转换为 React Flow 的显示属性（`label`、`style`、`markerEnd`），关系类型、颜色、粗细与箭头无法稳定反映到画布上。

**实现方案**

新增纯函数 `toDisplayEdges(edges)`，在渲染前把业务数据映射为 React Flow 显示属性：

| 业务字段（`RelationData`） | React Flow 显示属性 | 默认值 / 说明 |
| --- | --- | --- |
| `type` | `edge.label` | 未设置时不显示标签 |
| `color` | `style.stroke`、`labelStyle.fill`、`markerEnd.color` | `#333` |
| `width` | `style.strokeWidth` | `2` |
| `arrow` | `markerEnd = { type: ArrowClosed, color }` | 关闭或缺失时不显示箭头 |

补充显示细节：标签字号 12px，标签背景为白色、透明度 0.85，保证连线经过时文字可读。

**配套调整**

- `CanvasEditor` 使用 `useMemo(() => toDisplayEdges(edges), [edges])` 派生显示边，显示属性不写回 store，避免派生状态污染持久化数据。
- 从 `frontend/src/types.ts` 的 `RelationData` 中删除 `label` 字段。
- 删除属性面板“标注文字”输入框，关系类型输入框提示改为“显示在连线上，如师徒”。
- 工具栏按钮文案“重做”改为“恢复”，与设计文档术语统一（底层 `redo` 行为与快捷键不变）。

**兼容性说明**

- 已保存的 `.rmap` / JSON 文件中若含 `data.label`，加载时会被忽略，不会报错；`type` 成为连线标签的唯一来源。
- 若旧数据将“关系类型”和“标注文字”分开填写，旧标注文字将不再显示，需要用户确认是否需要数据迁移。

**关键文件**

| 文件 | 说明 |
| --- | --- |
| `frontend/src/core/canvas/edgeDisplay.ts` | 新增，纯函数映射显示属性 |
| `frontend/src/core/canvas/edgeDisplay.test.ts` | 新增，4 条单测 |
| `frontend/src/components/canvas/CanvasEditor.tsx` | 使用派生边，移除标注输入框 |
| `frontend/src/components/canvas/CanvasToolbar.tsx` | “重做”改为“恢复” |
| `frontend/src/types.ts` | 删除 `RelationData.label` |

**验证**

`edgeDisplay.test.ts` 覆盖：关系类型转标签、颜色与粗细、箭头开关、缺省值。4 条用例全部通过（详见第 6 节）。

### 3.3 前端路由鉴权守卫 + JWT 有效期延长（`398019a`，已提交）

**问题**

- axios 响应拦截器已处理 401 跳转登录页，但路由层未做守卫，未登录用户可直接访问 `/` 与 `/project/:id` 并看到页面壳。

**实现**

- 新增 `RequireAuth` 组件：读取 `localStorage.accessToken`，缺失时 `<Navigate to="/login" replace state={{ from: location.pathname }} />`，否则渲染子内容。
- `App.tsx` 使用 `RequireAuth` 包裹 `/` 与 `/project/:id`，未匹配路由重定向到 `/`。
- 后端 `AuthService.sign` 的令牌有效期由 `15m` 调整为 `7d`；代码注释说明 V1 无刷新令牌机制，后续引入 refresh token 后恢复短时效。

**验证**

新增 `RequireAuth.test.tsx`，覆盖无 token 重定向登录页、有 token 渲染受保护内容 2 条用例。

**限制与风险**

- 登录成功后 `LoginPage` 统一跳转 `/`，守卫写入的 `state.from` 暂未被消费，登录后不会自动回到原目标页。
- 7 天长效 token 是 V1 的可用性折中；无刷新令牌机制时，令牌泄露风险窗口较长，后续应补充 refresh token / 轮换与登出失效策略。

## 5. 当前架构与关键实现

### 5.1 代码结构

```
frontend/src/
├── api/                 # axios 客户端与 auth / projects / canvas 接口
├── components/          # 画布、角色节点、弹窗、搜索、布局、鉴权守卫
├── core/
│   ├── canvas/          # 连线显示派生（新增）
│   ├── export/          # PNG / JSON 导出
│   ├── shortcuts/       # 键位表
│   └── storage/         # Tauri / Web 本地保存
├── pages/               # 登录页、首页、工作区
├── stores/              # auth / project / canvas（Zustand）
└── types.ts             # CharacterData / RelationData / CanvasState

backend/src/
├── auth/                # 注册、登录、JWT、守卫
├── projects/            # 项目 CRUD
├── canvases/            # 画布读写与乐观锁
└── users/               # 用户实体
```

### 5.2 数据流

- **Web 画布**：`WorkspacePage` 加载画布 → Zustand `canvasStore` → React Flow 渲染；保存时携带 `baseVersion`，后端版本不一致返回 409 `VERSION_CONFLICT`，前端提示刷新。
- **显示派生**：连线在渲染前经 `toDisplayEdges` 转换为 React Flow 的 `label` / `style` / `markerEnd`，持久化数据中仍只保存业务字段。
- **PC 本地文件**：桌面环境通过 Tauri dialog + fs 直接读写 `.rmap` JSON；Web 环境保存降级为浏览器下载，打开本地文件仅在桌面端可用。
- **鉴权**：登录令牌存于 `localStorage.accessToken`；axios 请求自动注入 Bearer；401 时清除 token 并跳转登录页；路由层由 `RequireAuth` 兜底。
- **开发启动**：Vite 端口 1420，`/api` 代理到 `http://localhost:3000`；根目录 `concurrently` 同时启动前后端。
